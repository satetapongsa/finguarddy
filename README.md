# FinGuard AI – Demo (โหมดจำลอง)

เวอร์ชันทดลองเล่นของ FinGuard AI หน้าตาและการใช้งานเหมือนระบบจริง
แต่ข้อมูลและผลวิเคราะห์ทั้งหมดจำลองในเบราว์เซอร์ ไม่เรียก AI หรือ AWS

## รันในเครื่อง
npm install
npm run dev

## Deploy บน Vercel
Import repo นี้ใน Vercel แล้วกด Deploy ได้เลย ไม่ต้องตั้ง Environment Variables
